# Topaz Trove

Full-colour Python 3 neon minesweeper arcade for ElbowOS.

Sweep a glowing 8×12 grid. Reveal safe cells for score. Hit a mine and the board resets with a boom. Flood-fill zeros, particle sparks, warm gold / magenta / cyan neon.

## Play

```bash
pip install -r requirements.txt
python3 topaz_trove.py --play
```

Left-click cells. R to reset. Esc to quit.

## Record a 9:16 reel

```bash
python3 topaz_trove.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
